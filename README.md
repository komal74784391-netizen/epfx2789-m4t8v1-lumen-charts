# Lumen Chart Kit

**Status:** Released · v2.1.0 · 2026-01-27

Accessible chart primitives for Lumen dashboards.  All renderers share one
tooltip model and one legend component so dashboards stay visually consistent.

## Install

```bash
pip install lumen-charts
```

## What is in this repository

- `src/lumen_charts/chart.py` — line/area/bar renderers
- `src/lumen_charts/legend.py` — shared legend
- `tests/test_chart.py` — snapshot tests
